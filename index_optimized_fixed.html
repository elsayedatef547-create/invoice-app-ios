محوّل الفواتير إلى قائمة فحص

حوّل فواتيرك (صورة أو PDF) إلى قائمة منتجات تفاعلية بسهولة وسرعة

🔑 مفتاح Gemini غير مضاف
  1. افتح aistudio.google.com/apikey وسجّل الدخول بحساب Google.
  2. اضغط Create API key ثم انسخ المفتاح.
  3. الصقه هنا واضغط حفظ.

المفتاح يُحفظ على هذا الجهاز فقط ولا يُرسل إلا إلى Google.

▦ ربط جوجل شيت غير مربوط

الصق رابط تطبيق الويب المنتهي بـ /exec وكلمة السر التي وضعتها في الكود.
